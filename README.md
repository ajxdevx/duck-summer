# Duck Summer

A playful summer-themed Psyduck scene built with HTML and SCSS.

## Features

- Animated Psyduck character with hover interactions
- Summer sky with soft clouds and sun rays
- Water shimmer and glow reflection effects
- Multicolor swim ring
- Custom watermelon cursor
- Optional beach-wave ambient sound toggle

## Project Structure

- `index.html` - page markup and lightweight interaction script
- `styles.scss` - source styles (SCSS)
- `styles.css` - compiled CSS output

## Run Locally

1. Open `index.html` directly in your browser, or
2. Use a local server of your choice for live refresh.

## SCSS Build

Compile styles:

```bash
npx sass styles.scss styles.css
```

Watch mode:

```bash
npx sass --watch styles.scss:styles.css
```
