# Duck Summer

A playful summer-themed Psyduck scene built with HTML and SCSS.

## Features

- Animated Psyduck character with hover interactions
- Summer sky with soft clouds and sun rays
- Water shimmer and glow reflection effects
- Multicolor swim ring
- Custom watermelon cursor
- Optional beach-wave ambient sound toggle

## Project Structure

- `index.html` - page markup and lightweight interaction scripts
- `assets/audio/beach-seagulls.mp3` - beach ambient audio
- `assets/styles/styles.scss` - source styles (SCSS)
- `assets/styles/styles.css` - compiled CSS output

## Run Locally

1. Open `index.html` directly in your browser, or
2. Use a local server of your choice for live refresh.

## SCSS Build

Compile styles:

```bash
npx sass assets/styles/styles.scss assets/styles/styles.css
```

Watch mode:

```bash
npx sass --watch assets/styles/styles.scss:assets/styles/styles.css
```
